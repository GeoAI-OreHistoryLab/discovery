# geo-ai

Discovery materials and research for the GeoAI / mining intelligence platform ([GeoAI-OreHistoryLab](https://github.com/GeoAI-OreHistoryLab)).

## Contents

- `discovery/` — strategy, competitor analysis, NI 43-101 reference corpus, and interview notes.

Large archives (`.zip`) are tracked with [Git LFS](https://git-lfs.com/).

## Clone

Install [Git LFS](https://git-lfs.com/) if you do not already have it, then run it once on your machine before cloning (or right after):

```bash
git lfs install
git clone https://github.com/GeoAI-OreHistoryLab/discovery.git
cd discovery
```

If you cloned before installing LFS, run `git lfs install` and then `git lfs pull` to fetch LFS objects.
